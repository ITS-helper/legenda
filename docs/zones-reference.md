# Справочник зон (zona)

> Опорный документ проекта. Значение поля `zona` (отчёт 11 AA/BLE) и
> `chosen_ble_tag_zone` (отчёт 10) декодируется по этой таблице. Все подписи зон
> на сайте, в письмах и в коде берутся отсюда. Машинная копия —
> [`src/lib/zones.ts`](../src/lib/zones.ts).

## Классификация (тип) рабочих зон

| Код зоны | Описание |
|----------|----------|
| 1 | Зоны проведения работ |
| 2 | Столовые |
| 3 | Опасные зоны |
| 4 | Курилки |
| 5 | Зоны отдыха внутри и рядом. Пункты обогрева, пункты отдыха и т.п. |
| 6 | ВЖГ. Там, где люди в часах в теории вообще не должны появляться |
| 7 | Туалеты (внутри) |
| 8 | Остановки автобусов |
| 9 | Административные помещения (СБ, саппорт) |
| 10 | Зона выдачи WW |
| 11 | Склад (внутри и снаружи) |
| 12 | Мастерские (мастера, прорабы) |
| 13 | КПП |
| 14 | Стройгородок (зона отдыха) |

## Группировка для аналитики

Для сводных показателей зоны группируются так:

- **Рабочая зона (ПВ):** `1`
- **Зоны отдыха / перерывы (ПП):** `2` (столовые), `4` (курилки), `5` (отдых/обогрев), `14` (стройгородок)
- **Служебные / прочие:** `8` (остановки), `9` (админ), `10` (выдача WW), `11` (склад), `12` (мастерские)
- **Санитарные:** `7` (туалеты)
- **Контроль / нарушения:** `3` (опасные зоны), `6` (ВЖГ — не должны находиться), `13` (КПП)

Группировка — прикладная (для дашборда/рассылки) и может уточняться. Числовые
коды и названия — из официального справочника заказчика.

## Замечания

- `zona = 6` (ВЖГ) и `zona = 13` (КПП) — потенциальные нарушения (сотрудник там,
  где его быть не должно), их стоит подсвечивать.
- Историческое допущение «`zona = 1` = рабочая зона (ПВ)» подтверждается справочником.
- Пустая / неизвестная `zona` трактуется как «Не определено».
